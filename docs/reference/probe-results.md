# H6125 实测结果（2026-11-08，在一条 H6125 上目视确认）

| 参数 | 结论 | 依据 |
|---|---|---|
| segment_count | **15** | bit 0–14 全部点亮；bit 15 设红色时灯带上看不到红色；bit 14 设红色时最后一段变红 |
| bit_order | **start_at_plug**（不反转） | bit 0 在灯带起点（插头端），bit 14 在末端。帧索引 0 = 灯带起点 |
| brightness_max | **100** | 白光下亮度 100 与 255 来回切换，看不出差别 |
| max_packets_per_s | **25** | 移动白点测试：10、20 包/秒显示正常（低速一格一格移动，高速时平滑）；第一次 40 包/秒时连接断开，复测 30、40 包/秒各 5 秒未断。取 25 留余量 |
| scene_cmd_version | **1** | 极光 cmdVersion 0：在滑动但明显卡顿；cmdVersion 1：平滑、缓慢流动，先设全红再下发后整条都是极光色 |

补充：Govee 情景库 240 个效果变体中只有 2 个 `speedInfo.supSpeed=true`（Thanksgiving），极光不支持调速。

## 由实测得出的需求
- 动态效果需要可调速度。
- 利用分段（IC）让颜色渐变更明显；只用所选颜色，不额外混入白色。
