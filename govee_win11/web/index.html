    语言 / Language
    自动：跟随 Windows 的显示语言
    设备

    只支持 H6125。搜索前请先断开手机 Govee App；电脑正连着的灯带不会出现在搜索结果里。

    开机自启
    登录 Windows 后自动在托盘运行，并恢复上次的效果 / 同步模式
    开关机/睡眠时自动开关灯带
    关机、重启、注销或睡眠时关闭灯带；开机自启或从睡眠唤醒后打开灯带，并恢复上次的模式
    过渡方式（实验）
    每段每秒刷新次数

    超过 5 次时灯带可能卡在过渡中

    混合方式

    光强：两种颜色按真实光线叠加；人眼：按屏幕颜色值直接混合。对动态效果、投影、屏幕同步、音乐律动立即生效，可边看边比较。

    颜色校准（白平衡）

    先点「白」，调到灯带的白色和屏幕上的白色一致；一般只需要把偏多的颜色往下调。

    关于

    非官方的 Govee H6125 Windows 控制台：通过蓝牙直连灯带，不需要云端或账号。与 Govee 公司无关联。

    窗口

    最小化 = 隐藏到托盘，效果继续运行；关闭窗口 = 停止所有模式、断开蓝牙并退出。

    只有动态效果、屏幕同步、音乐运行时才一直连着灯带；其他时候用完就断开，手机 App 可以随时连。
