# Govee Win11 — H6125 灯带 Windows 控制台

[English](README.md) | 简体中文

**非官方**的 Windows 桌面控制台，用来控制 **Govee H6125 RGBIC 灯带**。它通过**蓝牙低功耗
（BLE）**直接和灯带通信：不需要云端、不需要 Govee 账号，也不需要联网。界面支持双语
（**自动 / 中文 / English**，在「设置 → 语言」切换；「自动」跟随 Windows 的显示语言）。

## 功能

- **分段配色与调色板**：给 15 个灯段分别上色、整条填充、保存调色板，并提供配色推荐。
- **效果**：内置效果，以及自己调的 **DIY** 效果（颜色、速度、多个效果混合）。单个效果的
  DIY 会**上传到灯带**上自己运行，电脑可以关机（需在「设置」里关闭「开关机/睡眠时自动开关灯带」；
  它默认开启，关机时会关掉灯带）。
- **Govee 情景库**：Govee 效果库里的 H6125 情景，直接发送到灯带。
- **屏幕同步**：灯带跟随屏幕画面的颜色，四种模式：**默认**、**淡入淡出**、**投影**、
  **区域**（动态壁纸也可以）。
- **音乐律动**：读取电脑正在播放的声音（WASAPI 回环采集，不用麦克风）。
- **颜色校准**（白平衡）：让灯带的白色和屏幕上的白色一致。
- **开关机联动**：Windows 关机、重启、注销或睡眠时关闭灯带；登录或唤醒后打开灯带，并恢复
  上次的模式。
- **托盘与开机自启**：最小化到通知区域，可选开机自动启动。

## 安装

**发布版（推荐）**

1. 在 [Releases](https://github.com/nvmmonkey/govee-win11/releases) 页面下载
   `GoveeWin11-v<版本>-win64.zip`。
2. 解压到任意位置（例如 `文档\GoveeWin11`）。
3. 运行 `GoveeWin11.exe`。

设置和日志保存在 `%APPDATA%\GoveeWin11`。

**从源码运行**

需要 Windows 上的 Python 3.12。

```
pip install -r requirements.txt
python -m govee_win11
```

从源码运行时，设置和日志保存在仓库的 `user_data/` 文件夹。

## 首次使用

1. **先断开手机。** 灯带同一时间只接受一个蓝牙连接：请先关闭手机上的 Govee App（或关闭
   手机蓝牙）。
2. 启动程序。它会**自动找到你的 H6125**（蓝牙名以 `Govee_H6125` 或 `ihoment_H6125`
   开头），使用信号最强的那条并记住它。
3. 如果你有多条灯带，打开「设置 → 设备」，点「搜索设备」后选择要用的那条。「忘记设备」
   会回到自动搜索。

如果状态显示「未找到灯带」，请确认灯带已通电、手机 App 已断开；程序会自动重试。

## 提示与限制

- 只在 **H6125** 上测试过。其他 Govee RGBIC 灯带的指令或灯段数可能不同。
- 灯带固件会把每次灯段颜色变化做平滑过渡，每个灯段每秒大约只能接受 **5 次更新**；更快
  的更新可能让灯带卡在过渡中（可在「设置 → 过渡方式（实验）」里尝试其他速率）。
- 需要 **Windows 10 或 11**，以及支持**蓝牙低功耗**的蓝牙适配器。
- 界面使用 **Microsoft Edge WebView2 Runtime**，Windows 11 已自带（Windows 10 上如果窗口
  一直空白，请从微软官网安装）。
- 只有动态效果、屏幕同步、音乐律动运行时电脑才一直连着灯带；其他时候每条指令发完不久就
  断开，手机 App 可以随时再连。

## 工作原理

程序使用灯带自己的 BLE 协议：向灯带的 GATT 特征写入 20 字节的指令帧，情景和 DIY 效果用
多包上传，分段颜色用灯段位掩码。逆向得到的细节（包括灯带上 DIY 效果的存储格式）记录在
[`docs/reference/govee-diy-format.md`](docs/reference/govee-diy-format.md)。

## 开发

```
pip install -r requirements-dev.txt
pytest
```

测试不会连接真实的灯带。打包发布版（PyInstaller，单文件夹）：

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

`build.ps1` 会生成 `dist\GoveeWin11\`，用 `GoveeWin11.exe --selftest` 自检（加载所有依赖
和资源，不开窗口、不连蓝牙），再打包成 `dist\GoveeWin11-v<版本>-win64.zip`。
